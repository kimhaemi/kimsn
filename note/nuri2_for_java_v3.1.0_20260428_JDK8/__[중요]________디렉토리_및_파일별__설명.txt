##★누리2 연동 안내
────────────────────────────────────────────────────────────
[◆ 누리2 설명 ◆]
* [누리2][Nuri2]는 독립 실행형 데몬입니다.
 - Java Library가 아닙니다.
 - 상시 기동 유지 해야합니다.
 - ★ 메시지 테이블(NRMSG_DATA)에 입력된 데이터를 처리하는 방식
 - ★ 입력, 조회, 통계등 기능 개발이 필요합니다.
 - DB 방식이므로 가능하면 DBA 권한 필요 합니다
 - 테이블 및 Sequence를 자동 생성됩니다. 수동생성 권장하지 않습니다.
 - 모듈 기동 및 데이터(입력예제) 입력 결과 회신등 처리 과정에 대한 모든 로그를 남깁니다.

[◆ 연동 테스트 절차 ◆]
 1. 모듈기동   : ID, PWD, DB접속 nuri2.conf 파일 환경 설정
 2. 메시지입력 : 예제 대로 샘플 메시지입력, 동작확인
 3. 프로그램 개발 : java(jsp) 및 기관 내부 발송기능 개발
 4. 자체 데이터 검증 : 메시지입력 규격대로 개발된 데이터 검증, 전달 할 메시지 내용 전달 확인
 5. 모바일메시지서비스 운영에 개발 데이터 검증요청 : 규격 확인, 미준시 개선 요청 등 수정 후 서비스 개시.

[◆ nuri2.jar(누리2) 파일명 안내◆]
nuri2.jar은 단순 파일명입니다. 버전을 구분하기 위해 파일명을 nuri2로 설정.
nuri3.jar nuri4.jar 등 이름을 자유롭게 변경가능 합니다.
 - 다만 파일명을 다르게 하는 경우는 nuri2.jar가 2개이상 실행 해야 할 경우에만 변경 권장
 - 설치경로 및 로그파일 경로도 각각 설정이 필요합니다.

* 실행시에도 변경된 파일명으로 실행 가능 합니다.
예) nuir2_test.jar, nuir2_test.conf 일경우
        nohup /자바홈/java -jar nuir2_test.jar nuir2_test.conf &
예) nuir2_work.jar, nuir2_work.conf 일경우
        nohup /자바홈/java -jar nuir2_work.jar nuir2_work.conf &

*[중요]* 발송 제한 조건
* 발송 제한 : 계정 차단(정지) 처리
1. 메시지 규격 미준수시
 - SMS(90byte) : 한글2byte 최대 45자.
 - LMS(91byte ~ 2000byte : 한글byte 최대 1000자.
 - MMS(LMS:2000byte + JPG:300KB, JPG:300KB) :  LMS와 JPG, JPG 단독.
 - ALT 1000자(Length) : 전체 1000자(줄바꿈 '\n' 1자)
 - RCS-SMS(RCS) 100자, RSC-LMS(RCL) 1300자, RCS-MMS(RCM) 1300자 + 이미지파일(JPG 이외 포멧지원)

 - 수신자가 스팸으로 신고한 경우.(횟수 알 수 없음)
 - 메시지 내용이 템플릿으로 생각되지 않는 의미없는 내용인경우
