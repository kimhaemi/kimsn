======================================================
* 일부 윈도우 설치 후  실행오류 조치방법
======================================================
1. JAVA install 시
======================================================
 아래 파일 확인
 * 인스톨(install) 버전의 경우는 자동으로 copy 됨.
 - C:\Windows\System32\msvcr100.dll
 * 마지막으로 설치한 JAVA 버전을 패스로 설정
 예) C:/Program Files/java/java-1.8.0-openjdk/ 일경우
-------------------------------
파일 : nuri2_Windows_Serviceinstall.bat
-------------------------------
@echo off
SET JAVA_HOME=C:/Program Files/java/java-1.8.0-openjdk/
.... 생략
-------------------------------
======================================================
2. 무설치버전 JAVA 이용시
======================================================
 예) java-1.8.0-openjdk 로 누리2 기동시
 압축을 해제한 경로이동
 C:/JAVA/java-1.8.0-openjdk/jre/bin 에서 msvcr100.dll 파일을 복사해서
 C:/Windows/System32/ 경로에 붙여넣음.

 아래 파일을 열고 패스 수정.
-------------------------------
파일 : nuri2_Windows_Serviceinstall.bat
-------------------------------
@echo off
SET JAVA_HOME=C:/JAVA/java-1.8.0-openjdk/
.... 생략
