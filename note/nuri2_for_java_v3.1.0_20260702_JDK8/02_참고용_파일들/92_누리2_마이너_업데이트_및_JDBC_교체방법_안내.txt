	Unix, Linux 버전
	**********************************************************************************
	#경로이동(누리2 설치경로를 /home/nuir2 로 안내)
        cd /home/nuri2/
	------------------------------------------------------------------------------------------------
	1) 누리2 기동 확인( nuri2.jar 파일 확인)
	------------------------------------------------------------------------------------------------
	- sh nuri2_launcher.sh list 또는 ps -ef|grep nuri2.jar |grep -v grep 실행 정보확인
	 예) hostname(계정)/home/NURI2>ps -ef|grep nuri2.jar |grep -v grep
	     계정     9937     1  0 01:02 ?        00:02:24 java -jar ..nuri2.jar

        ------------------------------------------------------------------------------------------------
        2) 누리2 정지(kill)(Unix, Linux)
        ------------------------------------------------------------------------------------------------
	# 누리 pid 검색
         ps -ef|grep nuri2.jar |grep -v grep

        #예) pid 검색 결과
        hostname(계정)/home/nuri2/>ps -ef|grep nuri2.jar |grep -v grep
         계정     9937     1  0 01:02 ?        00:02:24 java -jar ..nuri2.jar

        # kill 권장 ( -9 옵션은 종료가 되지 않을 때 : kill -9 pid)
        # kill 9937
        kill $(ps -ef | grep nuri2.jar | grep -v grep | awk '{print $2}')


        # 종료 확인 ( *중요* 약 종료까지 약 10~ 20초 소요 *중요*)
        ps -ef|grep nuri2.jar |grep -v grep




	------------------------------------------------------------------------------------------------
	3) 누리2 파일 교체(Unix, Linux)
	------------------------------------------------------------------------------------------------
	 # * 기존 버전 이름 변경 nuri2_old.jar

	 mv nuri2.jar nuri2_old.jar

	 # * 신규 버전 이름 nuri2.jar로 변경

         mv nuri2_1xx.jar nuri2.jar

	------------------------------------------------------------------------------------------------
	4) 누리2 기동(Unix, Linux)
	------------------------------------------------------------------------------------------------
         #누리기동 확인
         ps -ef|grep nuri2.jar |grep -v grep

         #[1] O/S(서버) local(언어) 재설정.(euckr)  : 'locale -a|grep ko' 확인 utf8 적용
         export LANG=ko_KR.utf8

	 #모듈 기동.
         nohup java -jar nuri2.jar nuri2.conf > /dev/null &

         #누리2 기동 확인
         ps -ef|grep nuri2.jar |grep -v grep

         # 기타 : /usr/java/bin/java -jar nuri2.jar nuri2.conf 만 입력하면 화면(콘솔)에 로그를 바로 표시. [Ctrl]+[c] 또는 터미널을 닫으면 종료 됨
         # 기타 : java -jar nuri2.jar nuri2.conf 만 입력하면 화면(콘솔)에 로그를 바로 표시. [Ctrl]+[c] 또는 터미널을 닫으면 종료 됨

	------------------------------------------------------------------------------------------------
	1) 기존 버전 백업(중요)
	------------------------------------------------------------------------------------------------
	* nuri2.jar(누리2) 설치 경로 확인(nuri2.jar 파일 위치)
	  - nuri2.jar(or nuri2.jar), nuri2.conf 백업

	* 현재 사용 중인 DB(데이터베이스) 확인(일부 DB의 경우 jdbc 드라이버 교체필요함.)
	  - Altibase의 경우 버전 별로 jdbc 필수 교체
	  - Mysql은 5.2.x 버전이 일부 호환이 되지않아 교체필요.
	  * JDBC 드라이버교체는 필수 아님. 일부 DB에서만 교체가 필요함.

	------------------------------------------------------------------------------------------------
	1. [* 참고] jdbc 드라이버 교체 방법.(1)
	------------------------------------------------------------------------------------------------
	1.1) 압축 해제, 재압축
	------------------------------------------------------------------------------------------------
	 가) PC에서 nuri2.jar 을 nuri2.zip으로 확장자 변경 후 압축풀기( nuri2/)
	 나) nuri2/ 경로 아래 해당 DB에 맞는 jdbc 파일로 교체
	    예) Cubrid 는  /NURI2/cubrid/ 이며 해당 cubrid/ 디렉토리를 삭제 후 현재 사용중 인 jdbc 압축 해제후  /NURI2/cubrid/ 로 교체
	 다) nuri2/이동 후 전체 선택 zip(*Windows 기본 압축기능 이용)파일로 압축 후 nuri2.zip을 nuri2.jar 로 변경
	 라) 모듈 기동
	------------------------------------------------------------------------------------------------
	1.2) UI 화면에서(반디집이 설치된 시스템, 기타 압축툴도 가능), Cubrid 일때
	------------------------------------------------------------------------------------------------
	 가) PC에서 nuri2.jar 반디집으로 압축파일 열기
	 나) nuri2/ 경로 아래 해당 DB에 맞는 jdbc 파일 경로 삭제
	    예) Cubrid 는  /NURI2/cubrid/ 이며 해당 cubrid/ 디렉토리 삭제
	 다) 현재 사용중 인 jdbc 압축 해제후  /NURI2/ 하위로 드레그 /NURI2/Cubrid 되도록 함.
	 라) 모듈 기동

	------------------------------------------------------------------------------------------------
	2) 환경설정 수정
	------------------------------------------------------------------------------------------------
	- 기존 환경설정 파일을 유지하셔도 메시지발송시 영향은 없습니다.
	- 변경시 nuri2.conf.sample 파일을 nuri2.conf 변경 후 기존 환경설정 값을 적용 권장
